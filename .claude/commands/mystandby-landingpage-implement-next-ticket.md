Use the Trello-backed
[`mystandby-landingpage-implement-next-ticket`](../../.github/skills/mystandby-landingpage-implement-next-ticket/SKILL.md)
skill for **myStandby Landing Page**. It selects the first ready card from
`Open`, moves it to `In Progress`, creates a branch, and runs the
Architect → Developer → Tester → Reviewer (AI Review Gate) workflow
described in [docs/agent-handbook.md](../../docs/agent-handbook.md). Trello
is authoritative; do not read a local backlog or ticket artifacts.
