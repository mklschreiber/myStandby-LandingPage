# myStandby Landing Page — app

Vue 3 + TypeScript + Vite single-page site. See
[docs/architecture/stack.md](../docs/architecture/stack.md).

```sh
npm install
npm run dev          # development server
npm run build        # type-check + production build
npm run test:unit    # Vitest
npm run lint         # ESLint (with --fix)
```

Screenshots live in `public/screenshots/` as `<id>-480.webp` and
`<id>-960.webp` (created with `cwebp -resize <width> 0`).
